01 About

I build the systems a company doesn't have yet. At a commercial solar EPC I've stood up the analytics warehouse, the internal knowledge layer, a contract-review engine that reads hundreds of obligations and tells legal exactly where the gaps are, and a lead engine built from public records that put a verified target list in front of the sales team.

The thread through all of it: real evaluation instead of demos, deterministic logic wherever a decision has to be auditable, models only where judgment is genuinely needed — and shipping into the tools people already use, because the best system nobody opens is worth nothing.

02 Systems I've shipped

Internal production systems, described at the capability level.

Contract-review engine

Extracts 500+ discrete obligations from long-form agreements and reconciles them against a standard template, producing a coverage matrix that routes each gap to the right reader. Calibrated on a hand-graded set at 92% gap recall with zero false positives.

The architecture is what makes it trustworthy: decision rules live in ~150 tested functions, with model reasoning confined to semantic matching — so legal review can check the logic instead of trusting a black box.

  • Applied LLMs
  • Document intelligence
  • Evaluation

Analytics warehouse

The company's first real data substrate: ingestion, dbt staging and marts with enforced model contracts, executive-facing views, CI, and scheduled orchestration on managed infrastructure — delivered as infrastructure-as-code on Azure.

Added historization to source systems that had none, turning point-in-time project data into a queryable time series and making schedule-slippage analysis possible for the first time.

  • dbt
  • Prefect
  • Azure · Bicep
  • SQL

Lead-generation engine

Public parcel and assessment records → filtered building spine → firmographic matching → multi-gate qualification → buying-committee enrichment → ranked, contact-ready target list with per-row rationale. Every candidate passes adversarial verification before a human picks up a phone.

Refactored from a script pile into a config-driven engine: entering a new market is a profile file plus reference data, no code change.

  • Public-records pipelines
  • Adversarial verification
  • Config-driven design

Lesson-planning AI for Brilla Public Charter Schools

An AI layer for the network's ELA curriculum with two modes: a generator that turns a unit overview into a complete, teach-ready lesson plan grounded in the school's own teaching expectations, and a coach that walks a teacher through internalizing a plan in a multi-turn conversation before they step into the classroom.

Engineered for real deployment economics: right-sized models per mode and prompt caching put full-school usage in the tens of dollars per month.

  • Applied LLMs
  • Education
  • Prompt architecture

Knowledge platform & MCP server

A retrieval-backed knowledge base with per-user access isolation plus a shared organizational tier — delivered into staff members' existing AI assistants rather than a new app they'd have to remember to open.

Grounding and identifier guards took fabrications from 4 to 0 on a fixed evaluation. A shared MCP server exposes internal data and tooling as typed tools, with local and hosted OAuth entrypoints.

  • RAG
  • MCP
  • Access control

03 Research & projects

Autonomous MTG Arena agent

An ongoing harness for LLM-driven play of Magic: The Gathering Arena — widely cited as the most complex commercial game ever made. A vision-based perceive/decide/execute loop drives the real client across a fleet of VMs: template matching and OCR for perception, typed decision requests for the model, verified actuation for every click.

The project doubles as a lab for agent-engineering practice: adversarial multi-agent verification, log-first diagnosis, and evaluation gates on every mechanic before it ships.

  • LLM agents
  • Computer vision
  • Private repo — writeup on request

MTG analytics research

A body of published data research on Magic: The Gathering, including a mana-efficiency study across 4.7 million games, the 16-vs-17-lands question in Limited, a Curve Score deck metric, and Mana Bug — a downloadable app that analyzes your own Arena logs.
